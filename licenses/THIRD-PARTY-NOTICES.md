# Third-party notices

Universal Bridge fetches these pinned source dependencies at configure time:

- zlib 1.3.2 (`v1.3.2`), zlib License, for read-only gzip decompression.
- JSON for Modern C++ 3.12.0 (`v3.12.0`), MIT License, for bounded JSON parsing.

The upstream license files remain in each CMake dependency source tree. Release
packaging must include the applicable copyright and license texts before public
distribution.
