# Privacy status

The current command-line prototype is local-first and does not implement accounts, analytics, advertising, cloud synchronization, licence telemetry, or a hosted service. It processes user-selected project paths and can generate local diagnostics, backups, exchange files and research indexes.

Before a commercial release, every desktop, plug-in, service, mobile, crash-reporting, update, licensing and support component must have a documented data inventory, retention/deletion rules, security controls, consent basis where applicable, and a counsel-reviewed privacy notice. Diagnostic bundles must be previewable and must exclude project audio, credentials and private paths by default unless the user deliberately includes them.

This is an implementation-status statement, not a final privacy notice.
